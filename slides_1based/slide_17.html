Path Compression (Cơ Chế Sửa Chữa)

🔨 NÉN ĐƯỜNG ĐỊ TRONG FIND: Trên đường từ $x$ đi tìm Root, cập nhật lại con trỏ `parent` của tất cả các nút đi qua trỏ trực tiếp về Root đại diện! 
int find(int i) {
    if (parent[i] == i)
        return i;
    // Phép gán đệ quy nén đường đi
    return parent[i] = find(parent[i]);
}

Sau khi nén: Cây bị ép phẳng tuyệt đối!

Các lần find tiếp theo chỉ tốn $O(1)$!

Hãy nhìn vào dòng code C++ kỳ diệu này: Chỉ bằng phép gán đệ quy parent[i] = find(parent[i]), tất cả các nút trên đường đi tìm Chủ tịch sẽ lập tức được nối thẳng trực tiếp tới vị Chủ tịch đó. Cây bị ép phẳng tuyệt đối.
