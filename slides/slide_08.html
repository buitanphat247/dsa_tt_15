C++ Execution Trace Hàm: search("car")
bool search(string word) {
  TrieNode* curr = root;
  for(char c : word) {
    int idx = c - 'a';
    if(!curr->children[idx])
      return false;
    curr = curr->children[idx];
  }
  return curr->is_end_of_word;
}
Ký tự c: - Con trỏ curr: Root Cờ is_end: -
Kính thưa Thầy và các bạn, đây là slide mô phỏng tương tác vi bước của thuật toán Trie: 1. Cây Trie được bố trí nằm ngang (từ Root sang phải) tương ứng trực tiếp với thứ tự đọc ký tự của chuỗi và luồng chạy của vòng lặp for trong C++. 2. Bạn có thể bấm nút "Bước Tiếp" hoặc "Tự Động" để minh họa 3 bài toán: - search("car"): Đi qua 'c' -> 'a' -> 'r', chạm N3 thấy is_end = true -> Trả về TRUE. - search("ca"): Đi qua 'c' -> 'a', dừng tại N2 thấy is_end = false -> Trả về FALSE. - insert("cart"): Tận dụng nhánh có sẵn "car" và cấp phát nút N5 mới cho ký tự 't'.
