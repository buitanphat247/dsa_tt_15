Phân Tích Chi Tiết: Memory Locality & Tác Động Phần CỨng CPU Cache

Bản chất phần cứng: CPU (3-5 GHz) nhanh gấp 100 lần RAM. Để tránh CPU đứng chờ RAM (Stall), kiến trúc máy tính dùng Cache Line (64 Bytes) để nạp sẵn dữ liệu lân cận vào bộ đệm L1/L2/L3.

Con Trỏ Phân Tán (Pointer Chasing)

HIGH CACHE MISSES

0x40F2

0x89C1
Node C
  • Cấu trúc đại diện: BST, Linked List, Trie Nodes, Hash Table Chaining.
  • Cơ chế RAM: Mỗi nút được cấp phát động (malloc/new) rải rác trên Heap.
  • Nguyên nhân chậm: Truy cập node->left bị Cache Miss $\implies$ CPU đứng chờ RAM ~200 chu kỳ clock (100ns) mỗi lần nhảy.
  • Cache Hit Ratio: Thấp ($\approx 15\% - 25\%$).

  • Cấu trúc đại diện: Union-Find (parent[], rank[]), Flat Array.
  • Cơ chế RAM: Cấp phát 1 khối bộ nhớ liên tục kề nhau trên RAM.
  • Lợi thế tốc độ: Đọc arr[0] nạp luôn 16 phần tử lân cận vào L1 Cache $\implies$ Các lần đọc sau trễ ~1ns (gần như 0s).
  • Cache Hit Ratio: Cực cao ($\approx 95\% - 99\%$).
Bảng thông số độ trễ bộ nhớ: L1 Cache: 1-2 ns L2 Cache: 3-5 ns L3 Cache: 10-20 ns 🐢 Main RAM: 50-100 ns (Chậm gấp 50-100 lần L1!)
Trên lý thuyết tiệm cận, hai giải thuật cùng Big-O chưa chắc chạy nhanh bằng nhau. Union-Find chạy cực nhanh vì mảng parent nằm liên tục trên RAM, CPU chỉ cần 1 lần nạp Cache Line là lấy được hàng loạt phần tử.
