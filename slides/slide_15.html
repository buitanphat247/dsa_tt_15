PHẦN III — CẤU TRÚC UNION-FIND (DSU)

Kỹ Thuật 1: Union by Rank

Cài Đặt C++ (Implementation)

C++ Code 
void unionByRank(int u, int v) {
    int rootU = find(u);
    int rootV = find(v);
    if (rootU == rootV) return;

    if (rank[rootU] < rank[rootV]) {
        parent[rootU] = rootV;
    } else if (rank[rootU] > rank[rootV]) {
        parent[rootV] = rootU;
    } else {
        parent[rootV] = rootU;
        rank[rootU]++; // Tăng rank khi 2 cây bằng nhau
    }
}
Khởi tạo ban đầu: Mảng parent[i] = i và mảng rank[i] = 0 với mọi $i \in \{0, \dots, N-1\}$.
Thuật toán chạy trong thời gian $O(1)$ tại bước gộp sau khi có Root.

Lý Thuyết Giải Thuật (Theory)

Heuristic
1. Khái niệm Rank: rank[u] là cận trên của chiều cao cây (Upper Bound of Tree Height) tại gốc $u$.
2. Nguyên lý gộp: Luôn gán gốc của cây có rank nhỏ hơn làm con của cây có rank lớn hơn. Chiều cao chỉ tăng $+1$ khi hai cây có cùng rank.
3. Định lý chặn chiều cao: Một cây có rank $k$ cần tối thiểu $2^k$ nút để hình thành $\implies 2^k \le N \implies \mathbf{H \le \lfloor \log_2 N \rfloor}$.
Độ phức tạp thao tác: $\mathcal{O}(\log N)$
ĐỊNH HƯỚNG TỐI ƯU TIẾP THEO: Union by Rank đảm bảo chiều cao cây không quá $\mathcal{O}(\log N)$. Để đạt tốc độ tiệm cận hằng số $\mathcal{O}(1)$, giải thuật sẽ kết hợp thêm Path Compression (Slide 16).
Kính thưa Thầy và các bạn, ở Slide 15, chúng ta tìm hiểu Kỹ thuật 1: Union by Rank: 1. Về cài đặt code: Hàm unionByRank nhận 2 đỉnh u và v, tìm 2 gốc rootU và rootV. Nếu rank của rootU nhỏ hơn rootV, ta gán parent[rootU] = rootV; ngược lại gán parent[rootV] = rootU. Chỉ khi 2 cây cùng rank, ta mới gán và tăng rank lên 1. 2. Về lý thuyết giải thuật: - Rank là cận trên của chiều cao cây, khởi tạo bằng 0. - Quy tắc: Luôn gắn cây rank nhỏ vào cây rank lớn, nhờ đó chiều cao cây lớn không bị thay đổi. - Định lý toán học: Một cây có rank k cần ít nhất 2^k nút để tạo thành. Vì vậy với N phần tử, chiều cao cây luôn bị chặn ở mức log2(N). 3. Kết quả: Độ phức tạp thao tác find() giảm từ O(N) xuống O(log N).
