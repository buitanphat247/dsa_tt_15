PHẦN III — CẤU TRÚC UNION-FIND (DSU)

Kỹ Thuật 1: Union by Rank (Gộp Theo Độ Sâu Ước Lượng)

Cài Đặt Chuẩn C++

Code Chuẩn CLRS 
void unionByRank(int u, int v) {
    int rootU = find(u);
    int rootV = find(v);
    if (rootU == rootV) return; // Đã cùng tập hợp

    // Cây thấp hơn làm con của cây cao hơn
    if (rank[rootU] < rank[rootV]) {
        parent[rootU] = rootV;
    } else if (rank[rootU] > rank[rootV]) {
        parent[rootV] = rootU;
    } else {
        parent[rootV] = rootU;
        rank[rootU]++; // Chỉ tăng khi 2 cây bằng nhau!
    }
}
Khởi tạo ban đầu: Mọi phần tử đều có parent[i] = i và độ sâu ước lượng rank[i] = 0.
Thời gian bước gộp: $\mathcal{O}(1)$

Bản Chất Lý Thuyết & Nguyên Lý

Dễ Hiểu — Trực Quan
1. Rank là gì? Tại sao gọi là "Ước lượng chiều cao"?
rank[u] chính là cận trên của chiều cao cây (Upper Bound) tại gốc $u$. Khởi đầu mỗi nút đứng một mình có $\text{rank} = 0$.
2. Quy tắc gộp thông minh (Luôn gắn cây lùn vào cây cao):
  • Khác rank: Cây thấp gắn làm con cây cao $\implies$ Chiều cao cây lớn không hề bị tăng!
  • Cùng rank: Gán cây nào cũng được, và duy nhất lúc này rank mới tăng $+1$.
3. Chứng minh toán học: Tại sao luôn đảm bảo $\mathcal{O}(\log N)$?
Để rank tăng lên $k$, cần gộp 2 cây cùng rank $k-1$. Cây rank $k$ cần ít nhất $2^k$ nút:
$2^k \le N \implies k \le \log_2 N \implies \mathbf{\text{Chiều cao } H \le \lfloor \log_2 N \rfloor}$
Chiều cao tối đa mọi thao tác: $\mathcal{O}(\log N)$
ĐỊNH HƯỚNG TỐI ƯU TIẾP THEO: Union by Rank đã triệt tiêu hoàn toàn nguy cơ cây suy biến thành chuỗi thẳng ($O(N)$), giữ chiều cao $\le \mathcal{O}(\log N)$. Để chạm tới tốc độ tiệm cận $O(1)$, ta sẽ kết hợp thêm Path Compression (Slide 16).
Kính thưa Thầy và các bạn, ở Slide 15, chúng ta tìm hiểu Kỹ thuật 1: Union by Rank: 1. Về cài đặt code: Hàm unionByRank nhận 2 đỉnh u và v, tìm 2 gốc rootU và rootV. Nếu rank của rootU nhỏ hơn rootV, ta gán parent[rootU] = rootV; ngược lại gán parent[rootV] = rootU. Chỉ khi 2 cây cùng rank, ta mới gán và tăng rank lên 1. 2. Về lý thuyết giải thuật: - Rank là cận trên của chiều cao cây, khởi tạo bằng 0. - Quy tắc: Luôn gắn cây rank nhỏ vào cây rank lớn, nhờ đó chiều cao cây lớn không bị thay đổi. - Định lý toán học: Một cây có rank k cần ít nhất 2^k nút để tạo thành. Vì vậy với N phần tử, chiều cao cây luôn bị chặn ở mức log2(N). 3. Kết quả: Độ phức tạp thao tác find() giảm từ O(N) xuống O(log N).
